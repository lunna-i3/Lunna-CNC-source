# Lunna CNC source
# an free and open source Command and Control server made in python

# ~> banners and customization (Banners/ & Settings/)

 You can modify the join banner in the Banners page, and create banners for additional commands
 The cnc source from default comes with just a help command banner and join banner
 with the command already attached
 same with commands banner in Banners/ or create another commands in Settings > config.json > commands 
 To create a main banner(banner when u login on the cnc) u can create a .tfx file on Banners/ called "banner"
 To modify the command line banner, create a cmd_line tfx file and reload the cnc

# ~> Super user commands


 reload                 # Reload the cnc assets, configurations, commands and funnel
 users                  # Show the users options.(not fully coded yet)
 erase                  # To remove attacks(not coded yet)


# ~> Commands that cant be remade:


 ongoing                # cant be remade on the banners part(u can modify it on code if u want) 
 debug                  # cant be remade on the banners part(u can modify it on code if u want)


# ~> funnel.json / attack informations


 {LEN}                  # len number that was used (Example: 512)
 {GEO}                  # geolocation (Example: BR)
 {RPS}                  # requests per second (Example: 100)
 {HOST}                 # targeted host (Example: 70.70.70.70)
 {PORT}                 # targeted port (Example: 80)
 {TIME}                 # attack duration (Example: 20)
 {METHOD}               # method that was used (Example: HTTP-NODUS)
 {CONCURRENTS}          # concurrents/default concurrents will go here (Example: 1)


# ~> response type = string


 <&spinner>             # Var to an spinner [- / | \ -] (only use on titles)
 <&user.name>           # Returns the current user name
 <&user.uptime>         # Returns how much time user is logged
 <&user.until_expiry>   # Returns How much time the customer have until expiry (Example: 31 days)
 <&user.createdby>      # Returns who created the user account
 <&cnc.uptime>          # Returns How long the CNC has been online for (Example: 21 days)
 <&cnc.name>            # Returns CNC name set in the Name section of Settings > config.json


# ~> response type = int

 
 <&users.count>           # Returns the actives users on the cnc 
 <&user.running>          # Return how many concurrents the user is using
 <&cnc.running>           # Return how many concurrents are being used on the cnc
 <&cnc.globalconcurrents> # Return how many concurrents can be used on the entire cnc
 <&user.boottime>         # Return the max boottime of the user
 <&user.concurrents>      # Return the max concurrents of the user
